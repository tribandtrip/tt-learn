# Prompt para generar el curso personalizado con Claude

Una vez recibas el diagnóstico de tu alumno, copia este prompt y pégalo en Claude
junto con el JSON del informe. Claude te generará el índice del curso adaptado.

---

## PROMPT (copiar y pegar en Claude)

```
Actúa como diseñador instruccional especializado en formación de IA para autónomos creativos.

Tengo el diagnóstico inicial de mi alumna. Con estos datos, genera:

1. **Índice del curso personalizado** (8-12 sesiones de 1.5-2h)
   - Para cada sesión: título, objetivo, herramientas a usar, ejercicio práctico concreto
   - Ordenado de menor a mayor complejidad
   - Adaptado a su nivel real, su negocio y sus objetivos concretos

2. **Prioridades detectadas** (qué trabajar primero y por qué)

3. **Alertas para el formador** (puntos de atención, posibles bloqueos, adaptaciones necesarias)

4. **Primera sesión detallada** (guion completo con tiempos, ejercicios y deberes)

Datos del diagnóstico:
[PEGA AQUÍ EL JSON DEL INFORME]
```

---

## Dónde encontrar el JSON

El JSON del diagnóstico se guarda automáticamente en:
- **Google Drive** → Alumnos → [Nombre alumno] → Diagnóstico [fecha]
- **Google Sheet** → pestaña "Diagnósticos" → última fila
